交易板范围

默认只选沪深主板（与历史基线一致）。勾选后，该交易板的股票统一参与完整筛选：资金增量与状态 → 超短池／趋势池 → 双池交集 → 资金优选／低吸／明日观察池 → 现有状态机，使用同一套门槛与排名 （三板都读 tools/rule_config.py，暂不单独放大两板阈值；超出现有涨幅/价格区间的股票被排除属正常筛选结果）。 取消勾选则该板不参与新增候选；已持仓股票的监控不受影响。北交所暂不在选项内。至少选择一个交易板。

此设置对本实例的所有访问者生效（单实例共享配置）。切换范围后，旧范围留下的锁存/等待回踩状态会被剔除（已持仓保留监控）。

固定规则（只读）
  • 超大单为负：禁止正式买入建议（真实仓一票否决）
  • 真实仓主导资格须为 absolute
  • 公告 avoid/unknown：一票否决

规则语义以《选股框架.md》为准；本页不能改变这些门禁，也没有普通开关可关掉它们。
