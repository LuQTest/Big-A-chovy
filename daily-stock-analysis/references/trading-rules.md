# daily-stock-analysis · 决策边界说明

本文件不再维护第二套交易规则。`daily-stock-analysis` 只负责筛选、指标计算、报告生成和状态记录；最终买卖、仓位、持仓、T+1 和真实仓权限由 `盘中` skill 按根目录《选股框架.md》裁决。

## 固定权威层级

1. `盘中` skill：实际决策入口、盘问流程和复盘流程；
2. `选股框架.md`：信号层级、硬门槛、一票否决、买点、离场、仓位和待验证规则；
3. `决策记录/YYYYMMDD.md`：真实执行、模拟执行、持仓快照和次日计划；
4. `daily-stock-analysis`：发现层输入，不得覆盖上面三层。

## 发现层可以输出的内容

- 经过时间戳和数据源标注的行情、K 线、均线、VWAP、资金、公告、板块和市场宽度字段；
- 严格超短、趋势、低吸和明日观察池的筛选结果；
- `A/B/C`、`strict/hopeful`、`追高风险`、`数据不足` 等筛选标签；
- 候选出现、消失、资金衰减和状态变化，供 `盘中` 复核。

这些标签只表示筛选层结果，不代表“可买”“应卖”“允许持仓”或任何仓位比例。

## 调用约束

- 用户询问买卖、持仓、仓位、T+1 或复盘时，先返回筛选证据，再交由 `盘中` skill 按《选股框架.md》裁决；
- 不在本目录重复定义或修改交易阈值；
- 不把 `watch_risk`、`avoid`、`unknown` 的筛选字段自行解释成最终交易许可；
- 不把筛选结果写入真实仓；
- 影子样本和 T+1 结算统一由 `tools/shadow_tracker.py` 管理，未完成样本不得进入交易结论。

旧版详细交易规则已停止作为本工具的决策依据；需要查看正式规则时，直接读取《选股框架.md》和 `盘中` skill。
